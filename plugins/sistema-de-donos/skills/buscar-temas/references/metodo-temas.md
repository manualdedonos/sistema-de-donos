# Método de busca de temas para carrossel

## As 7 minas de tema (onde cavar)

1. **Dor dita na língua do cliente.** A frase que o cliente fala no WhatsApp, no balcão, na primeira consulta ("não sei se vale a pena", "já tentei de tudo", "tá caro"). O tema é a resposta honesta a essa frase.
2. **Contra-senso do setor.** O que todo mundo no segmento repete e está errado ou incompleto ("preciso postar todo dia", "cliente só quer preço"). O post desmonta a crença com um mecanismo e um exemplo.
3. **História com número.** Um caso real (do próprio negócio, de um cliente anonimizado ou público e verificável) com um número no meio: antes/depois, quanto custou, quanto tempo levou.
4. **Bastidor.** Como a coisa é feita por dentro: o processo, o erro que quase ninguém vê, a decisão difícil. Gera confiança porque mostra competência sem dizer "sou bom".
5. **Pergunta frequente.** A dúvida que o usuário responde toda semana. Se ele responde toda semana, o público inteiro tem essa dúvida.
6. **Mudança no mundo.** Lei nova, tecnologia nova, tendência, dado recente que afeta o público (IA, reforma tributária, fim da 6x1, sazonalidade). Ângulo: "o que isso muda pra você, na prática".
7. **Grande referência traduzida.** Um artigo, livro, estudo ou caso famoso (Sequoia, Coca-Cola, Nike, um estudo de Harvard) traduzido para a realidade do pequeno negócio. Funciona porque empresta autoridade e surpresa.

## Teste de força (um tema passa se marcar 4 de 5)

- **Específico**: dá para imaginar a cena, a pessoa, o número. "Como precificar" falha; "por que o seu serviço de R$ 150 deveria custar R$ 240" passa.
- **Tensão**: tem um "mas", uma quebra de expectativa, um erro ou um risco. Sem tensão, não há motivo para passar o slide.
- **Prova**: há um mecanismo, um dado, um caso ou uma referência que sustenta a tese (não só opinião).
- **Relevância agora**: toca uma dor do público do perfil hoje (não um assunto que o dono acha interessante).
- **Promessa cumprível em 10–14 slides**: cabe num carrossel sem virar curso.

## Formato padrão de uma sugestão de tema

```
**N. Título de trabalho**
- Ângulo: …
- Por que para pra ler: …
- Gancho provisório: …
- O que o post entrega: a · b · c
```

## Sinais de tema fraco (descarte ou reescreva)

- Começa com "A importância de…" ou "Dicas para…".
- Serve para qualquer negócio do planeta.
- A tese é consenso (ninguém discordaria).
- Precisa de dados que o usuário não tem e não pode confirmar.
- O que o post entrega é o mesmo que o CTA vende (não sobra iceberg).

## Como variar os 3 temas

Combine: um de dor/pergunta frequente (alcance), um de contra-senso ou referência traduzida (autoridade), um de história/bastidor (confiança). Ou, com objetivo definido pelo usuário, três ângulos diferentes para o mesmo objetivo.
